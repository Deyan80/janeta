# Janeta Osipova — Official Page

Luxury editorial portfolio website.

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "Initial deploy"
git remote add origin https://github.com/YOURUSERNAME/janeta.git
git push -u origin main
```

Then: **Settings → Pages → Source: main / root**

## Facebook Share

Update `og:url` and `og:image` in `<head>` with your real GitHub Pages URL:
```
https://YOURUSERNAME.github.io/janeta/
```

Facebook will show `janeta-share.jpg` as the preview image.

## Files
- `index.html` — Complete site with all images embedded (works offline, no server needed)
- `janeta-share.jpg` — Facebook OG preview image (1200×630)
